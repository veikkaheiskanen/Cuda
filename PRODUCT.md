## Platform
adaptive

## Product Purpose
Personal music playback and discovery across Spotify, YouTube, YouTube Music, SoundCloud and imported audio, built for Apple Silicon.

## Capabilities and Constraints
Home contains recommendations, last played and playlists. Shelf combines favourites, playlists and imported songs. Playback automatically chooses matching sources, with manual source selection in Now Playing. Spotify account setup, selected playlist imports and recommendation taste are user requested. The macOS interface is being replaced with native SwiftUI/AppKit using real Liquid Glass; iOS uses native SwiftUI. Existing source resolution and Rust Spotify DSP remain backend helpers. No Electron/Chromium/web view may ship in the native Mac application.
