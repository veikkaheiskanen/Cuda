# Cuda native promo images

Three 3200 × 1800 PNGs (16:9): Home, Shelf, and the expanded player. Prepared on 11 October 2026 for Cuda Native 1.0.2.

These are promotional compositions of real native SwiftUI app captures from an isolated demo profile. Cuda Sessions is an illustrative library with original artwork; no private user library, Spotify account information, or third-party album covers are shown. System accent color was retained. App captures are scaled and cropped for presentation, removing the titlebar and screen-sharing indicator; their interface is not AI-generated or repainted. The player is shown paused.

The pearl and blue glass background was generated with the built-in image generation tool (new image, opaque background), then placed behind real screenshots and separately typeset HTML/CSS copy. The pack includes the original background, unchanged screen captures, editable HTML layouts, and the static export script. Its rendering tool is for marketing assets only and is not part of the native Cuda app.
